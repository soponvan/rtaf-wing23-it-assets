เชื่อมต่อฐานข้อมูลกลางออนไลน์ (Cloud Real-time)

ซิงค์ข้อมูลคอมพิวเตอร์แบบเรียลไทม์ ใช้ร่วมกันได้ทุกเครื่องใน บน.23

💡 การทำงานของระบบ Real-time:

เมื่อเชื่อมต่อฐานข้อมูลกลาง (เช่น Firebase Realtime Database หรือ API องค์กร) ทุกครั้งที่มีการเพิ่ม/แก้ไขข้อมูลจากคอมพิวเตอร์เครื่องใดก็ตาม ข้อมูลจะอัปเดตไปยังหน้าจอของทุกคนใน บน.23 แบบเรียลไทม์ทันที และข้อมูลจะถูกบันทึกถาวรบนคลาวด์ ไม่สูญหายแม้จะเปลี่ยนเครื่องหรือล้างประวัติเบราว์เซอร์

รองรับ Google Firebase Realtime Database (ฟรี 100% ไม่มีค่าใช้จ่าย)

สถานะการเชื่อมต่อ: โหมดจัดเก็บในเครื่อง (Local Storage)

สำรองและกู้คืนข้อมูลสินทรัพย์

1. ดาวน์โหลดไฟล์สำรองข้อมูล (JSON Backup)

เซฟข้อมูลเครื่องทั้งหมดเป็นไฟล์ `.json` เก็บไว้ในเครื่องหรือ Flash Drive เพื่อป้องกันข้อมูลหาย 100%

2. กู้คืน / นำเข้าข้อมูล (Restore)

เลือกไฟล์ `.json` หรือ `.csv` ที่เคยสำรองไว้ เพื่อนำข้อมูลทั้งหมดกลับคืนสู่ระบบทันที
